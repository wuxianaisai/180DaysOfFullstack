## About

**180DaysOfFullstack** — This is my 180‑day journey from the basics of web development to creating a full‑fledged full‑stack application.

Every day I study a new topic, write code, complete practical assignments, and make at least one significant commit.

The repository contains:

* theory and notes;
* practical exercises;
* programming tasks;
* small applications;
* full‑fledged projects;
* a ready‑made fullstack application.

The main principle:

> **Learn → Practice → Build → Commit**
